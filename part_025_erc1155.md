## 1. ERC-1155 คืออะไร? {#what-is-erc1155}

ERC-1155 คือ Multi-Token Standard ที่ช่วยให้ Contract หนึ่งจัดการทั้ง Fungible Token และ Non-Fungible Token พร้อมกัน

### เปรียบเทียบ Standards

```
ERC-20: 1 Contract = 1 Token Type (Fungible เท่านั้น)
  USDT Contract → ทุก Token เป็น USDT

ERC-721: 1 Contract = 1 NFT Collection
  BAYC Contract → ทุก Token เป็น BAYC NFT

ERC-1155: 1 Contract = Multiple Token Types
  Game Contract → Gold(ERC20-like) + Sword(ERC721-like) + Potion(100 copies)
```

### Use Cases

```
Gaming:
  tokenId 1 = Gold (Fungible, supply = 1,000,000)
  tokenId 2 = Legendary Sword (Non-Fungible, supply = 1)
  tokenId 3 = Health Potion (Semi-Fungible, supply = 500)

Digital Assets:
  tokenId 1 = Common Card (supply = 1000)
  tokenId 2 = Rare Card (supply = 100)
  tokenId 3 = Ultra Rare Card (supply = 10)
  tokenId 4 = Unique Card (supply = 1)

Tickets:
  tokenId 1 = General Admission (supply = 5000)
  tokenId 2 = VIP (supply = 100)
  tokenId 3 = Backstage Pass (supply = 10)
```

### ข้อดีของ ERC-1155

```
1. Gas Efficient: Batch Transfer ในครั้งเดียว
2. ยืดหยุ่น: Fungible + Non-Fungible ใน Contract เดียว
3. Semi-Fungible: Token ที่มีจำนวนจำกัด
4. ลด Deployment Cost: ไม่ต้อง Deploy หลาย Contract
```

## 3. Batch Operations {#batch-operations}

### ทำไม Batch ถึงประหยัด Gas?

```
ไม่มี Batch (ERC-721):
  Transfer 5 Items:
    tx1: transferFrom(Alice, Bob, tokenId1) → Gas: 50,000
    tx2: transferFrom(Alice, Bob, tokenId2) → Gas: 50,000
    tx3: transferFrom(Alice, Bob, tokenId3) → Gas: 50,000
    tx4: transferFrom(Alice, Bob, tokenId4) → Gas: 50,000
    tx5: transferFrom(Alice, Bob, tokenId5) → Gas: 50,000
    Total: 250,000 Gas

มี Batch (ERC-1155):
  safeBatchTransferFrom(Alice, Bob, [1,2,3,4,5], [1,1,1,1,1]) → Gas: 80,000
  Total: 80,000 Gas (ประหยัด 68%!)
```

### Batch Transfer Implementation

```vyper
# @version 0.4.0

balances: HashMap[address, HashMap[uint256, uint256]]
operatorApprovals: HashMap[address, HashMap[address, bool]]

event TransferBatch:
    operator: indexed(address)
    sender: indexed(address)
    receiver: indexed(address)
    tokenIds: DynArray[uint256, 100]
    values: DynArray[uint256, 100]

@external
def safeBatchTransferFrom(
    sender: address,
    receiver: address,
    tokenIds: DynArray[uint256, 100],
    amounts: DynArray[uint256, 100],
    data: Bytes[1024]
):
    """
    @notice โอน Tokens หลายชนิดพร้อมกัน
    """
    assert sender == msg.sender or self.operatorApprovals[sender][msg.sender], \
        "ERC1155: caller not owner nor approved"
    assert receiver != empty(address), "ERC1155: transfer to zero address"
    assert len(tokenIds) == len(amounts), "ERC1155: ids and amounts length mismatch"
    
    # ทำ Transfer ทีละ Token
    for i: uint256 in range(100):
        if i >= len(tokenIds):
            break
        
        tokenId: uint256 = tokenIds[i]
        amount: uint256 = amounts[i]
        
        assert self.balances[sender][tokenId] >= amount, "ERC1155: insufficient balance"
        
        self.balances[sender][tokenId] -= amount
        self.balances[receiver][tokenId] += amount
    
    log TransferBatch(msg.sender, sender, receiver, tokenIds, amounts)

@external
@view
def balanceOfBatch(
    accounts: DynArray[address, 100],
    tokenIds: DynArray[uint256, 100]
) -> DynArray[uint256, 100]:
    """
    @notice ดู Balance ของหลาย Account/Token ในครั้งเดียว
    """
    assert len(accounts) == len(tokenIds), "ERC1155: length mismatch"
    
    result: DynArray[uint256, 100] = []
    
    for i: uint256 in range(100):
        if i >= len(accounts):
            break
        result.append(self.balances[accounts[i]][tokenIds[i]])
    
    return result
```

## 4. Semi-fungible Tokens {#semi-fungible}

Semi-fungible Token คือ Token ที่มีจำนวนจำกัดแต่ไม่ใช่ Unique

```
Fungible (ERC-20 style):
  Gold Coin: supply = 1,000,000 → แต่ละเหรียญเหมือนกัน

Non-Fungible (ERC-721 style):
  Legendary Sword #1: supply = 1 → ชิ้นเดียวในโลก

Semi-Fungible (ERC-1155 แบบจำกัด):
  Rare Card "Dragon": supply = 100 → มี 100 ใบ แต่แต่ละใบ "เหมือนกัน"
  แต่ทุกใบ Dragon Card มีค่าเท่ากัน ต่างจาก NFT
```

```vyper
# @version 0.4.0
"""
@title Semi-fungible Token Example
@notice แสดงการใช้ ERC-1155 กับ Token Types ต่างๆ
"""

struct TokenType:
    name: String[100]
    maxSupply: uint256
    currentSupply: uint256
    isFungible: bool  # True = ERC20-like, False = Limited Edition

tokenTypes: HashMap[uint256, TokenType]
nextTokenTypeId: uint256

@deploy
def __init__():
    self.nextTokenTypeId = 1

@external
def createFungibleToken(name: String[100]) -> uint256:
    """สร้าง Token ชนิด Fungible (ไม่จำกัด Supply)"""
    typeId: uint256 = self.nextTokenTypeId
    self.nextTokenTypeId += 1
    
    self.tokenTypes[typeId] = TokenType({
        name: name,
        maxSupply: max_value(uint256),  # ไม่จำกัด
        currentSupply: 0,
        isFungible: True
    })
    
    return typeId

@external
def createSemiFungibleToken(
    name: String[100],
    maxSupply: uint256
) -> uint256:
    """สร้าง Token ชนิด Semi-Fungible (จำกัด Supply)"""
    assert maxSupply > 0, "Supply must be positive"
    
    typeId: uint256 = self.nextTokenTypeId
    self.nextTokenTypeId += 1
    
    self.tokenTypes[typeId] = TokenType({
        name: name,
        maxSupply: maxSupply,
        currentSupply: 0,
        isFungible: False
    })
    
    return typeId

@external
def createNonFungibleToken(name: String[100]) -> uint256:
    """สร้าง Token ชนิด Non-Fungible (Supply = 1)"""
    return self.createSemiFungibleToken(name, 1)
```

## 5. Implementation in Vyper {#implementation}

```vyper
# @version 0.4.0
"""
@title ERC-1155 Multi-Token Standard
@notice Implementation ครบถ้วนตาม EIP-1155
"""

# ==================== Interfaces ====================

interface IERC1155Receiver:
    def onERC1155Received(
        operator: address,
        sender: address,
        tokenId: uint256,
        value: uint256,
        data: Bytes[1024]
    ) -> bytes4: nonpayable
    
    def onERC1155BatchReceived(
        operator: address,
        sender: address,
        tokenIds: DynArray[uint256, 100],
        values: DynArray[uint256, 100],
        data: Bytes[1024]
    ) -> bytes4: nonpayable

# ==================== Events ====================

event TransferSingle:
    operator: indexed(address)
    sender: indexed(address)
    receiver: indexed(address)
    tokenId: uint256
    value: uint256

event TransferBatch:
    operator: indexed(address)
    sender: indexed(address)
    receiver: indexed(address)
    tokenIds: DynArray[uint256, 100]
    values: DynArray[uint256, 100]

event ApprovalForAll:
    owner: indexed(address)
    operator: indexed(address)
    approved: bool

event URI:
    value: String[512]
    tokenId: indexed(uint256)

# ==================== Constants ====================

ERC1155_RECEIVED: constant(bytes4) = 0xf23a6e61
ERC1155_BATCH_RECEIVED: constant(bytes4) = 0xbc197c81
ERC1155_INTERFACE_ID: constant(bytes4) = 0xd9b67a26
ERC165_INTERFACE_ID: constant(bytes4) = 0x01ffc9a7

# ==================== State Variables ====================

owner: public(address)
paused: public(bool)

# token balances: owner => tokenId => balance
balances: HashMap[address, HashMap[uint256, uint256]]

# operator approvals: owner => operator => approved
operatorApprovals: HashMap[address, HashMap[address, bool]]

# Token URI
baseURI: String[256]
tokenURIs: HashMap[uint256, String[512]]

# Token Supply Tracking
totalSupply: public(HashMap[uint256, uint256])
maxSupply: public(HashMap[uint256, uint256])  # 0 = unlimited

@deploy
def __init__(_baseURI: String[256]):
    self.owner = msg.sender
    self.baseURI = _baseURI

# ==================== ERC-165 ====================

@external
@view
def supportsInterface(interfaceId: bytes4) -> bool:
    return (
        interfaceId == ERC165_INTERFACE_ID or
        interfaceId == ERC1155_INTERFACE_ID
    )

# ==================== ERC-1155 Core ====================

@external
@view
def balanceOf(account: address, tokenId: uint256) -> uint256:
    assert account != empty(address), "ERC1155: zero address"
    return self.balances[account][tokenId]

@external
@view
def balanceOfBatch(
    accounts: DynArray[address, 100],
    tokenIds: DynArray[uint256, 100]
) -> DynArray[uint256, 100]:
    assert len(accounts) == len(tokenIds), "ERC1155: length mismatch"
    
    result: DynArray[uint256, 100] = []
    for i: uint256 in range(100):
        if i >= len(accounts):
            break
        result.append(self.balances[accounts[i]][tokenIds[i]])
    
    return result

@external
def setApprovalForAll(operator: address, approved: bool):
    assert operator != msg.sender, "ERC1155: setting approval for self"
    assert operator != empty(address), "ERC1155: zero address"
    
    self.operatorApprovals[msg.sender][operator] = approved
    log ApprovalForAll(msg.sender, operator, approved)

@external
@view
def isApprovedForAll(account: address, operator: address) -> bool:
    return self.operatorApprovals[account][operator]

@external
def safeTransferFrom(
    sender: address,
    receiver: address,
    tokenId: uint256,
    amount: uint256,
    data: Bytes[1024]
):
    """
    @notice โอน Token ชนิดเดียว
    """
    assert not self.paused, "ERC1155: paused"
    assert (
        sender == msg.sender or
        self.operatorApprovals[sender][msg.sender]
    ), "ERC1155: caller not owner nor approved"
    
    self._safeTransferFrom(sender, receiver, tokenId, amount, data)

@external
def safeBatchTransferFrom(
    sender: address,
    receiver: address,
    tokenIds: DynArray[uint256, 100],
    amounts: DynArray[uint256, 100],
    data: Bytes[1024]
):
    """
    @notice โอน Token หลายชนิดพร้อมกัน
    """
    assert not self.paused, "ERC1155: paused"
    assert (
        sender == msg.sender or
        self.operatorApprovals[sender][msg.sender]
    ), "ERC1155: caller not owner nor approved"
    
    self._safeBatchTransferFrom(sender, receiver, tokenIds, amounts, data)

# ==================== URI ====================

@external
@view
def uri(tokenId: uint256) -> String[512]:
    """
    @notice URI สำหรับ Token Metadata
    """
    individualURI: String[512] = self.tokenURIs[tokenId]
    if len(individualURI) > 0:
        return individualURI
    
    if len(self.baseURI) > 0:
        return concat(self.baseURI, uint2str(tokenId), ".json")
    
    return ""

# ==================== Internal Functions ====================

@internal
def _safeTransferFrom(
    sender: address,
    receiver: address,
    tokenId: uint256,
    amount: uint256,
    data: Bytes[1024]
):
    assert receiver != empty(address), "ERC1155: transfer to zero address"
    assert self.balances[sender][tokenId] >= amount, "ERC1155: insufficient balance"
    
    self.balances[sender][tokenId] -= amount
    self.balances[receiver][tokenId] += amount
    
    log TransferSingle(msg.sender, sender, receiver, tokenId, amount)
    
    self._doSafeTransferAcceptanceCheck(msg.sender, sender, receiver, tokenId, amount, data)

@internal
def _safeBatchTransferFrom(
    sender: address,
    receiver: address,
    tokenIds: DynArray[uint256, 100],
    amounts: DynArray[uint256, 100],
    data: Bytes[1024]
):
    assert receiver != empty(address), "ERC1155: transfer to zero address"
    assert len(tokenIds) == len(amounts), "ERC1155: length mismatch"
    
    for i: uint256 in range(100):
        if i >= len(tokenIds):
            break
        
        tokenId: uint256 = tokenIds[i]
        amount: uint256 = amounts[i]
        
        assert self.balances[sender][tokenId] >= amount, "ERC1155: insufficient balance"
        
        self.balances[sender][tokenId] -= amount
        self.balances[receiver][tokenId] += amount
    
    log TransferBatch(msg.sender, sender, receiver, tokenIds, amounts)
    
    self._doSafeBatchTransferAcceptanceCheck(msg.sender, sender, receiver, tokenIds, amounts, data)

@internal
def _doSafeTransferAcceptanceCheck(
    operator: address,
    sender: address,
    receiver: address,
    tokenId: uint256,
    amount: uint256,
    data: Bytes[1024]
):
    if receiver.code_size > 0:
        returnValue: bytes4 = IERC1155Receiver(receiver).onERC1155Received(
            operator, sender, tokenId, amount, data
        )
        assert returnValue == ERC1155_RECEIVED, "ERC1155: non-receiver"

@internal
def _doSafeBatchTransferAcceptanceCheck(
    operator: address,
    sender: address,
    receiver: address,
    tokenIds: DynArray[uint256, 100],
    amounts: DynArray[uint256, 100],
    data: Bytes[1024]
):
    if receiver.code_size > 0:
        returnValue: bytes4 = IERC1155Receiver(receiver).onERC1155BatchReceived(
            operator, sender, tokenIds, amounts, data
        )
        assert returnValue == ERC1155_BATCH_RECEIVED, "ERC1155: non-batch-receiver"

@internal
def _mint(to: address, tokenId: uint256, amount: uint256, data: Bytes[1024]):
    assert to != empty(address), "ERC1155: mint to zero address"
    assert amount > 0, "ERC1155: zero amount"
    
    maxSup: uint256 = self.maxSupply[tokenId]
    if maxSup > 0:
        assert self.totalSupply[tokenId] + amount <= maxSup, "ERC1155: max supply exceeded"
    
    self.balances[to][tokenId] += amount
    self.totalSupply[tokenId] += amount
    
    log TransferSingle(msg.sender, empty(address), to, tokenId, amount)

@internal
def _mintBatch(
    to: address,
    tokenIds: DynArray[uint256, 100],
    amounts: DynArray[uint256, 100],
    data: Bytes[1024]
):
    assert to != empty(address), "ERC1155: mint to zero address"
    assert len(tokenIds) == len(amounts), "ERC1155: length mismatch"
    
    for i: uint256 in range(100):
        if i >= len(tokenIds):
            break
        
        tokenId: uint256 = tokenIds[i]
        amount: uint256 = amounts[i]
        
        maxSup: uint256 = self.maxSupply[tokenId]
        if maxSup > 0:
            assert self.totalSupply[tokenId] + amount <= maxSup, "ERC1155: max supply exceeded"
        
        self.balances[to][tokenId] += amount
        self.totalSupply[tokenId] += amount
    
    log TransferBatch(msg.sender, empty(address), to, tokenIds, amounts)

@internal
def _burn(from_: address, tokenId: uint256, amount: uint256):
    assert from_ != empty(address), "ERC1155: burn from zero address"
    assert self.balances[from_][tokenId] >= amount, "ERC1155: insufficient balance"
    
    self.balances[from_][tokenId] -= amount
    self.totalSupply[tokenId] -= amount
    
    log TransferSingle(msg.sender, from_, empty(address), tokenId, amount)

# ==================== Admin Functions ====================

@external
def mint(
    to: address,
    tokenId: uint256,
    amount: uint256,
    data: Bytes[1024]
):
    assert msg.sender == self.owner, "Not owner"
    self._mint(to, tokenId, amount, data)

@external
def mintBatch(
    to: address,
    tokenIds: DynArray[uint256, 100],
    amounts: DynArray[uint256, 100],
    data: Bytes[1024]
):
    assert msg.sender == self.owner, "Not owner"
    self._mintBatch(to, tokenIds, amounts, data)

@external
def burn(from_: address, tokenId: uint256, amount: uint256):
    assert (
        msg.sender == from_ or
        self.operatorApprovals[from_][msg.sender]
    ), "ERC1155: not owner nor approved"
    self._burn(from_, tokenId, amount)

@external
def setMaxSupply(tokenId: uint256, supply: uint256):
    assert msg.sender == self.owner, "Not owner"
    assert supply >= self.totalSupply[tokenId], "Below current supply"
    self.maxSupply[tokenId] = supply

@external
def setTokenURI(tokenId: uint256, _uri: String[512]):
    assert msg.sender == self.owner, "Not owner"
    self.tokenURIs[tokenId] = _uri
    log URI(_uri, tokenId)

@external
def setBaseURI(_uri: String[256]):
    assert msg.sender == self.owner, "Not owner"
    self.baseURI = _uri

@external
def pause():
    assert msg.sender == self.owner, "Not owner"
    assert not self.paused, "Already paused"
    self.paused = True

@external
def unpause():
    assert msg.sender == self.owner, "Not owner"
    assert self.paused, "Not paused"
    self.paused = False
```

## 6. ตัวอย่าง: Gaming Items Contract {#gaming-items}

```vyper
# @version 0.4.0
"""
@title Gaming Items Contract
@notice Multi-Token Contract สำหรับเกม RPG
@dev ใช้ ERC-1155 สำหรับ Items ทุกประเภท

        tokenId: uint256,
        value: uint256,
        data: Bytes[1024]
    ) -> bytes4: nonpayable
    
    def onERC1155BatchReceived(
        operator: address,
        sender: address,

struct CraftRecipe:

# ==================== Constants ====================

ERC1155_RECEIVED: constant(bytes4) = 0xf23a6e61
ERC1155_BATCH_RECEIVED: constant(bytes4) = 0xbc197c81

# Item IDs
GOLD: constant(uint256) = 1         # Fungible Currency
WOOD: constant(uint256) = 2         # Fungible Material
IRON: constant(uint256) = 3         # Fungible Material
HEALTH_POTION: constant(uint256) = 4  # Semi-Fungible (จำกัด 1000)
SWORD: constant(uint256) = 5        # Semi-Fungible (จำกัด 100)
SHIELD: constant(uint256) = 6       # Semi-Fungible (จำกัด 100)

# ==================== State Variables ====================

balances: HashMap[address, HashMap[uint256, uint256]]
operatorApprovals: HashMap[address, HashMap[address, bool]]

# Item Information

totalSupply: public(HashMap[uint256, uint256])

# Player Stats
playerXP: public(HashMap[address, uint256])
playerLevel: public(HashMap[address, uint256])

# Crafting
craftRecipes: HashMap[uint256, CraftRecipe]  # recipeId → CraftRecipe
recipeIngredients: HashMap[uint256, DynArray[(uint256, uint256), 10]]  # recipeId → [(itemId, amount)]

        description: "Currency of the realm",
        rarity: 0,
        maxSupply: 0,  # Unlimited
        isTradeable: True,
        craftable: False
    })
    
    # Wood - Crafting Material
    self.items[WOOD] = ItemInfo({
        name: "Wood",
        description: "Basic crafting material",
        rarity: 0,
        maxSupply: 0,
        isTradeable: True,
        craftable: False
    })
    
    # Iron - Crafting Material

        rarity: 1,

@external
def claimStarterPack():
    """
    @notice ผู้เล่นใหม่รับ Starter Pack
    """
    assert self.playerLevel[msg.sender] == 0, "Already claimed"
    
    # Set Level 1
    self.playerLevel[msg.sender] = 1
    
    # Mint Starter Items

    self._mint(msg.sender, WOOD, 50, b"")         # 50 Wood
    self._mint(msg.sender, HEALTH_POTION, 5, b"") # 5 Potions

@external
def craftItem(recipeId: uint256, amount: uint256):
    """
    @notice Craft Item ตาม Recipe
    """
    assert amount > 0, "Zero amount"
    
    recipe: CraftRecipe = self.craftRecipes[recipeId]
    assert recipe.isActive, "Recipe not active"
    
    # ตรวจสอบ Ingredients
    ingredients: DynArray[(uint256, uint256), 10] = self.recipeIngredients[recipeId]
    
    for ingredient: (uint256, uint256) in ingredients:
        requiredAmount: uint256 = ingredient[1] * amount
        assert self.balances[msg.sender][ingredient[0]] >= requiredAmount, \
            "Insufficient ingredients"
    
    # เผา Ingredients
    for ingredient: (uint256, uint256) in ingredients:
        requiredAmount: uint256 = ingredient[1] * amount
        self.balances[msg.sender][ingredient[0]] -= requiredAmount
        self.totalSupply[ingredient[0]] -= requiredAmount
    
    # Mint Result
    resultAmount: uint256 = recipe.resultAmount * amount
    self._mint(msg.sender, recipe.resultItemId, resultAmount, b"")
    
    # ให้ XP
    self.playerXP[msg.sender] += 10 * amount
    
    log ItemCrafted(msg.sender, recipe.resultItemId, resultAmount)

@external
def useItem(itemId: uint256, amount: uint256):
    """
    @notice ใช้ Item (เช่น ดื่ม Potion)
    """
    assert self.balances[msg.sender][itemId] >= amount, "Insufficient items"
    
    self._burn(msg.sender, itemId, amount)
    
    # Apply Effects (Simplified)
    if itemId == HEALTH_POTION:
        self.playerXP[msg.sender] += 5  # Heal gives XP
    
    log ItemUsed(msg.sender, itemId, amount)

# ==================== Internal Functions ====================

@internal
def _transfer(sender: address, receiver: address, tokenId: uint256, amount: uint256):
    assert receiver != empty(address), "Zero address"
    assert self.balances[sender][tokenId] >= amount, "Insufficient balance"
    
    self.balances[sender][tokenId] -= amount
    self.balances[receiver][tokenId] += amount

@internal
def _mint(to: address, tokenId: uint256, amount: uint256, data: Bytes[1024]):
    assert to != empty(address), "Zero address"
    
    maxSup: uint256 = self.items[tokenId].maxSupply
    if maxSup > 0:
        assert self.totalSupply[tokenId] + amount <= maxSup, "Max supply exceeded"
    
    self.balances[to][tokenId] += amount
    self.totalSupply[tokenId] += amount
    
    log TransferSingle(msg.sender, empty(address), to, tokenId, amount)

@internal
def _burn(from_: address, tokenId: uint256, amount: uint256):
    assert self.balances[from_][tokenId] >= amount, "Insufficient balance"
    
    self.balances[from_][tokenId] -= amount
    self.totalSupply[tokenId] -= amount
    
    log TransferSingle(msg.sender, from_, empty(address), tokenId, amount)
```

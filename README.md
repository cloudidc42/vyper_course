# หลักสูตร Vyper Smart Contract Development
## ตั้งแต่ระดับพื้นฐาน จนถึง ระดับมืออาชีพ และ ระดับโลก

---

## เกี่ยวกับหลักสูตร

หลักสูตรนี้ครอบคลุมการพัฒนา Smart Contract ด้วยภาษา **Vyper** บน Ethereum blockchain ตั้งแต่ระดับเริ่มต้นจนถึงระดับมืออาชีพ

### Vyper คืออะไร?
- ภาษา Smart Contract สำหรับ Ethereum
- ไวยากรณ์คล้าย Python
- ปลอดภัยกว่า Solidity ด้วยการออกแบบที่เน้น Security by Design
- ลด Attack Surface ด้วยการจำกัด Feature ที่ซับซ้อน
